## Mac 构建

依赖安装及前端构建见 DEVELOPMENT。`npm --prefix desktop run package:mac` 会冻结 Python 服务、构建原生辅助程序、收集第三方许可并运行签名校验。历史流程面向维护者的 Developer ID；源码不提供证书、私钥、公证凭据或生产发布权限。第三方须使用自己的签名身份，并审查应用标识、钥匙串服务、数据根目录和更新渠道，不能冒充官方签名发行。

源码自带的官方更新和产品账号适配代码不意味着获得服务资格。独立分发须配置自己的更新渠道，或禁用官方更新；不要将官方登录信息、更新授权策略或服务器私密配置提交仓库。`distribution/` 提供服务实现，不包含运行策略及凭据。

## 数据与许可

只处理授权资料；Data、数据库、媒体缓存、令牌与钥匙串材料不属于源码交付。维护或升级先备份并验证恢复，保留账号隔离与授权边界。

重新分发二进制须保留原代码许可及实际打包第三方组件的声明、对应源码与替换说明。构建脚本的许可收集和验证步骤不得跳过。参见 NOTICE 与 packaging/DISTRIBUTION-TERMS.txt。
