# 开源版功能

当前版本 **0.1.1**，支持本地微信账号连接、授权同步、关注与暂停、会话阅读、搜索、原消息定位、媒体缓存，以及 Skill / MCP 授权接入。

- 表情、动图、撤回提示和拍一拍可折叠为数量提示，单条也可折叠；展开保留原内容，正文中的表情不受影响。
- 自动、手动及已授权 AI 请求实际开始同步时重置倒计时，下次同步按本次触发时间加同步间隔计算。忙碌时被拒绝的请求不算新同步。
- 设置页支持统一样式的同步和更新操作、Skill 命令复制、本机连接控制，以及洪云微信名片二维码。底部提示为「后续更新请联系洪云」。
- 通过本公开仓库的 GitHub Release 检查后续更高正式版本，下载后在正常退出时安装。同版本修订不触发自动更新。

开源版不包含发现首页、洪云产品账号的登录注册与资格校验、会员更新渠道或 Nexus 账号联动。微信账号切换仍受资料库隔离保护。

支持系统与首次使用步骤见 [安装说明](INSTALL.md)，当前版本冻结约定见 [开发指南](DEVELOPMENT.md)。
